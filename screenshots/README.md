# ExamPro — Application Screenshots Guide

This directory holds representative application screenshots illustrating the ExamPro workflow and dark-themed UI/UX styling.

### Recommended Screen Captures

| Filename | View Description |
|---|---|
| `01-login.png` | Split-screen authentication view with ExamPro brand visual, input card, and inline alerts. |
| `02-dashboard.png` | Main assessment portal featuring greeting banner, Java Fundamentals exam card, and guidelines. |
| `03-profile.png` | Account profile view with editable Full Name and Email fields alongside validation badges. |
| `04-exam.png` | Active MCQ exam engine showing Question Card, 4 options, question progress, and timer. |
| `05-timer-warning.png` | Timer panel in warning/critical state (<= 60s and <= 30s) with color-coded alerting. |
| `06-submit-confirmation.png` | Exam submission dialog displaying answered vs. total questions summary. |
| `07-result.png` | Performance overview dashboard showing large score %, pass/fail badge, and metric cards. |
| `08-answer-review.png` | Question-by-question answer review modal highlighting user answers, correct answers, and explanations. |

Capture instructions:
1. Launch the application via `run.bat`.
2. Navigate through each workflow state and capture screenshots using your preferred capture tool (e.g., Windows Snipping Tool `Win + Shift + S`).
3. Save image files into this directory (`screenshots/`).
